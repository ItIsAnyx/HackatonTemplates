### Шаблоны для реализации простой ИИ-системы по апи ключу или с локальной моделью

#### Шаблоны:
- **Config_template.py** - шаблон конфига для подключения секретных ключей, а также валидации бэкенд-ключа;
- **Simple_API_template.py** - шаблон для подключения удалённой модели по API-ключу с возможностью загрузки файлов и поддержкой длительного диалога без доп. обработки контекста;

#### Примеры реализации:
- **AI_API_example** - Пример реализации AI-ассистента для анализа датасетов и генерации рекомендаций по Feature Engineering. Поддерживает ретривер, Langfuse, обработку загружаемого датасета, суммаризацию контекста, выполнение тестовых запросов на Python.
